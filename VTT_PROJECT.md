# VTT Project

## Project Maintenance Rules & Guides

- Only the user may create projects (see OPENCLAW_KB/project-creation-policy.md).
- Every project gets its own <PROJECT>.md file.
- All actions/changes logged with date and rationale.
- **All agent/subagent responses must start with a standardized header:**
  - Agent Name | Session Number | Project Name | Tasks
  - Example: BOB | Session #1043 | Project: VTT | Tasks: Health check & auto-respawn
  - See OPENCLAW_KB/response-format.md for template.
- Use headers in every section and update.
- Changes: append rather than overwrite for context/history.
- Commit/progress must be pushed to GitHub after each work session.
