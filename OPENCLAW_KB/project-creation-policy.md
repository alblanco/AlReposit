# Project Creation & Naming Policy

## Purpose
Define strict project governance: only the user may initiate, name, or approve new projects. This ensures work is always organized according to user intent and prevents unauthorized project proliferation.

## Policy
- **Only the human user may create projects.**
    - The assistant must never create, name, or initialize new projects.
    - All new project filenames, headers, and references are subject to user review/approval.
- **Official project names:**
    - As of now, the only recognized projects are:
        - VTT (voice-to-text)
        - Environment_setup
    - No other names/aliases may be used without explicit consent from the user.
- **Documentation & Onboarding:**
    - Policy referenced from BOOTSTRAP.md, LONG_TERM_MEMORY.md, and all <PROJECT>.md scaffolds.
